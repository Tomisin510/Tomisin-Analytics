# Business Intelligence Domain

## Overview
This folder is dedicated to bridging the gap between raw data and executive decision-making. The projects here focus on creating interactive dashboards, automated reporting, and clear KPI tracking that non-technical stakeholders can understand and act upon.

## Planned Projects
- **Executive Sales Dashboard**: A Power BI / Tableau dashboard tracking real-time sales, profit, and regional performance across multiple product lines.
- **Automated KPI Alerts**: Python scripts that scrape data, calculate key metrics, and send scheduled email reports (with visual attachments) to management.
- **Data Warehouse Modelling**: Designing star-schemas and fact/dimension tables for efficient querying in a cloud BI environment.

## Tools & Techniques
- **BI Tools**: Power BI, Tableau, Looker Studio.
- **ETL/Data Prep**: SQL (CTEs, window functions), Python (pandas), dbt (if applicable).
- **Reporting**: Jupyter to PDF/HTML, or automated Markdown reports.
