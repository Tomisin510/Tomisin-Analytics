# Operations Analytics Domain

## Overview
This folder focuses on improving internal business processes, supply chain efficiency, and resource allocation. The projects here aim to optimise the "engine room" of an organisation using data-driven decision-making.

## Planned Projects
- **Inventory Demand Forecasting**: Time-series models (Prophet, ARIMA, LSTM) to predict stock requirements and reduce carrying costs.
- **Process Bottleneck Analysis**: Using process mining or simulation to identify delays in manufacturing or logistics workflows.
- **Vendor Performance Scoring**: Building a composite scorecard to evaluate supplier reliability, cost, and lead times.

## Tools & Techniques
- **Python**: pandas, scipy, Prophet, pm4py (process mining).
- **Optimisation**: SciPy optimize, PuLP for linear programming.
- **Visualisation**: Gantt charts, flow diagrams, and time-series line plots.
