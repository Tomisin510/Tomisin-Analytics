# Geoscience Analytics Domain

## Overview
This domain applies data science techniques to the energy, mining, and environmental sectors. The focus is on interpreting spatial, subsurface, and sensor-derived data to support exploration and operational efficiency.

## Planned Projects
- **Subsurface Sensor Data Analysis**: Exploratory data analysis and anomaly detection on drilling or seismic sensor logs.
- **Spatial Mapping**: Using geospatial libraries to visualise resource distribution or environmental changes over time.
- **Predictive Maintenance**: Forecasting equipment failure in remote field operations using time-series sensor data.

## Tools & Techniques
- **Python**: pandas, geopandas, shapely, rasterio for spatial data.
- **Visualisation**: Folium, Matplotlib Basemap (or Cartopy).
- **Machine Learning**: Isolation Forest for anomaly detection; Random Forest for regression on subsurface properties.
